## 実行時の正本

新版は `games/hsr/data/` のJSONだけを読み込みます。旧 `data/hsr/`、旧 `games/data/hsr/`、CSV、XLSX、旧連番IDは実行・テストのどこからも参照しません。

| ファイル | 内容 | 計算への扱い |
| --- | --- | --- |
| `catalog.json` | 95キャラクター、165光円錐、60遺物・オーナメントセット、3敵カード。ゲーム内ID、基礎値、762スキル、1,912軌跡、570星魂、全光円錐の重畳別効果を含む。 | 名称・画像・フィルタ・詳細表示とLv80基礎値に使用。説明文は計算に使わない。 |
| `attacks.json` | 三月なのか、丹恒、姫子、ゼーレの代表攻撃14件。 | 明示したスキルIDとパラメータ添字から倍率を取得。未登録キャラクターは手動倍率と表示する。 |
| `modifiers.json` | 停雲、ブローニャ、ペラ、ルアン・メェイの代表サポート効果5件。 | 出典キャラ・スキルID、発動条件、対象範囲、軌跡Lv別数値、加算区分を構造化して適用する。 |
| `image-manifest.json` | 期待323件、利用可能323件、不足0件。 | 取得漏れを再生成時に検出する。 |

生成スクリプトは `scripts/syncHsrCatalog.py` です。上流JSONをリポジトリ直下へ保存せず、正規化したJSONだけを書き出します。`--images` を付けると不足画像だけを取得し、既存WebPを上書きしません。

## 計算式と検証範囲

- 通常ダメージ: 参照ステータスと明示倍率、ダメージバフ、被ダメージ増加、防御補正、属性耐性、靭性残存時0.9、会心を別乗算区分で処理する。
- 防御ダウンと防御無視: 同じ防御区分で加算し、合計100%を上限にする。
- 属性耐性: 0%未満は `1 - RES`、0～75%未満も `1 - RES`、75%以上は高耐性式を使う。弱点の有無だけで通常ダメージへ別の0.8倍を追加しない。
- 複数参照: ATK、HP、DEFを複数項として明示できる。説明文の解析はしない。
- 弱点撃破: Lv80係数3767.5533、属性倍率、撃破特効、防御、耐性、被ダメージ増加、`0.5 + 最大靭性 / 120` を使う。[Toughnessの係数表](https://honkai-star-rail.fandom.com/wiki/Toughness) と[日本語の独立検証資料](https://wikiwiki.jp/star-rail/%E3%83%80%E3%83%A1%E3%83%BC%E3%82%B8%E8%A8%88%E7%AE%97%E5%BC%8F)でLv80値を照合した。Lv80以外は未検証として計算しない。
- 行動値: `10000 / 速度` と、指定行動値枠内の基礎行動回数だけを扱う。行動順短縮、即時再行動、途中の速度変化、召喚物、割り込みは未対応と表示する。

## 自動対応と非対応

自動対応済みの攻撃は三月なのか、丹恒、姫子、ゼーレの代表14件です。丹恒の必殺技は「敵が減速状態」の追加倍率を攻撃専用条件として分離しています。拡散のメイン・隣接倍率、会心可否、弱点撃破を別結果として扱います。

自動対応済みのパーティ効果は、停雲の必殺技与ダメージ、ブローニャの戦闘スキル与ダメージ、ペラの必殺技防御ダウン、ルアン・メェイの戦闘スキル与ダメージと必殺技耐性貫通です。メンバーを置いただけでは発動せず、効果と発動条件を明示して有効化した場合だけ適用します。

全キャラクター、光円錐、星魂、軌跡、遺物セットの表示データは収録していますが、上記以外の固有効果を自動計算しません。光円錐・遺物・オーナメントの条件付き効果は詳細表示に留め、UIDから取得した最終ステータスまたは明示した手動補正だけを使います。未対応効果を推測で有効化しません。

## UID

本番では `worker.js` の `/games/api/hsr-profile` を経由してMiHoMo Parsed APIを利用し、同一オリジン経由が使えない場合だけAPI直結を試します。公開キャラクター、レベル、星魂、光円錐、重畳、遺物、セット、軌跡、APIが返す戦闘ステータスだけを初期値へ反映します。取得後は「UID取得値」、編集後は「UID取得値を手動変更」と表示します。APIから得られない値を補完しません。

2026-07-28の通し確認では、MiHoMoの公開サンプルUID `800333171` から8キャラクターを取得し、長夜月、光円錐「長き夜に輝く星へ」、遺物「天地再創の救世主」、オーナメント「静謐な拾骨地」、軌跡、最終ステータス（HP 8370.534、攻撃力 1502.599、防御力 1149.594、速度 101.3、会心率 68.312%、会心ダメージ 236.316%）の反映に成功しました。途中で上流の `Queue timeout` も発生したため、成功系に加えて待機タイムアウト時のエラー表示と再試行も実ブラウザで確認しています。レスポンス正規化、形式検証、保存、削除はfixtureによる自動テストでも確認しています。
