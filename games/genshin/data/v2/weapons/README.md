# Genshin weapon v2 evidence layer

This directory is materialized by `node scripts/genshinWeaponV2Generate.cjs`.
The transform copies explicit fields from `weapons.json`, `weapon-effects.json`,
`calc/weapon-modifiers.json`, and `calc/weapon-effect-registry.json`; it never
extracts values or targets from prose.  Consequently every generated spec is a
review-gated candidate (`verification.status: needsReview`,
`sourceAgreement: singleSource`) until a game-versioned independent source is
reviewed.

- `source-records.json`: integrity-checked source records and locators.
- `spec-candidates.json`: one effect spec candidate per legacy modifier.
- `verification.json`: verification/runtime projection for each spec.
- `packages/<weaponId>.json`: per-weapon source/spec/runtime links.
- `index.json` / `manifest.json`: deterministic counts and input digests.
- `audit.json`: generated by `node scripts/genshinWeaponV2Audit.cjs`.

The current materialization covers 210 weapons and 455 modifiers.  Runtime
statuses are `candidate` (454), `displayOnly` (1), and `canonical` (0); none is
promoted by text inference.
