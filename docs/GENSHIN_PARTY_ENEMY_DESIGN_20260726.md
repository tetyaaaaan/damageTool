# パーティ詳細モデル・敵プリセット設計

## 目的

単体キャラのダメージ計算を中心に保ったまま、残り3人から受けるバフを安全に計算する。パーティ全体DPSやローテーションは同じ画面へ混在させない。

## UI

- パーティ設定はページ上へカードを増やさず、既存の専用ダイアログ内に置く。
- 各枠のキャラと武器は、メイン入力と同じ検索・フィルタ・アイコン一覧を共有する。
- 選択済みキャラ、装備不能武器は候補から除外する。
- 基本設定は常時表示し、天賦と提供者ステータスは折りたたむ。
- スマホはキャラと武器を上下、基本項目を2列にし、横スクロールを発生させない。

## 状態と計算

- パーティスキーマはバージョン2とし、装備、基礎値、提供者ステータスをメンバーへ内包する。
- 基礎値はローカル同期データから解決し、総ステータスは必要な効果だけ任意入力する。
- 不足値を0と推測して適用せず、補正条件に理由付きで表示する。
- 武器効果もパーティ補正候補へ追加するが、装備者自身だけの効果は除外する。
- 同一発動元の完全重複と、ゲーム上重複不可の効果を別の規則として扱う。

## 敵

- プリセットは入力支援に限定し、計算リクエストには展開済み耐性を保存する。
- 標準元素耐性と元素別例外を分離し、スライム等の元素無効を正しく表現する。
- カスタムは常に先頭で編集可能とし、特定の敵を暗黙の初期条件にしない。
