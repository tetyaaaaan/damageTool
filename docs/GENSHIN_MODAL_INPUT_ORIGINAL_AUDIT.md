## 確認範囲

読込キャラクター 123、武器 255、聖遺物 63。実説明セクション {"character":511,"weapon":216,"artifact":100}。C6/4セットを使用。

- 表示上入力がない44件は重複込みのresourceEvent22レコード（エネルギー等）であり、単発ダメージ非該当。支持される実ダメージ効果の孤立条件は静的確認では残存0。
- ヴォジャニーツァC1/C2/C4は既存入力、C6は悠久の歌の共有状態を使用。自動導出の層数入力を増やさない。
- 共通入力の共有キーを既存条件評価キーにも接続。計算式は変更しない。
- 未発動0を維持。発動操作ONだけで最大段階へ移行し、0から最大まで変更可能。HP、人数、割合、実在しない合成スタックは最大化しない。
- 日本語API保存本文を優先し、raw/sourceText指定の保存日本語フィールドも改変せず出典付きで接続。Runtime summary、生成source-recordsは原文根拠にしない。
- utility天賦は実sourceIdへ解決。氷旅人の寒光加算は爆発全文へ統合し、共鳴も同じ親天賦へ統合。抜粋や独立本文のない空カードを作らない。
