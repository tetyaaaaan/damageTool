## 外部データの導入方針

- スキル倍率、軌跡、星魂、光円錐・遺物効果は、ゲーム内表記または公式情報を第一候補にする。
- OSS・公開データを導入する場合は、URL、取得日、対応ゲームバージョン、変換手順、ライセンス、商用利用と帰属表示の可否を同じ変更で記録する。
- [StarRailRes](https://github.com/Mar-7th/StarRailRes) はAGPL-3.0であり、ゲーム画像の権利も別途確認が必要なため、現時点でデータ・画像をコピーしない。
- 未検証の数値や条件は推測で補完しない。画面では手動入力に留め、計算対象外の理由を表示する。

## 画像マニフェスト

キャラクター画像は `games/images/hsr/characters/<既存CSV ID>.webp` を参照する設計です。現時点では安全に追加できる画像がないため、テーマ画像へフォールバックします。画像を追加する際は、出所・再配布可否・帰属要件をこの文書へ追記してください。
