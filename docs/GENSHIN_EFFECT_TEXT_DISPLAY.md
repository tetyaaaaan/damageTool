# 原神の効果説明と計算への反映

表示専用の原文は `games/genshin/data/original/effect-texts-ja.json` に出典とともに保存する。保存rawの日本語文、またはユーザーが外部確認した日本語原文を扱う。原文登録は計算仕様の検証・昇格を意味しない。

共通の `GenshinIdResolver.describeEffect` は `originalText` と `calculationSummary` を分離する。明示された原文だけを「原文」、明示的な部分引用だけを「原文抜粋」とする。補正モーダルでは原文未登録なら「原文未取得」と表示し、summaryや生成文で置き換えない。原文の存在や一致を推定しない。

補正モーダルの「計算への反映」は、共通表示モデルを通じて現在のRequestを既存Runtimeで評価した実補正値・単位・適用状態を示す。開いている攻撃詳細（未選択時は最初の計算可能な攻撃）が表示対象になる。ステータス補正はRuntime trace、攻撃別補正は既存のentry適用処理を参照し、説明文や生係数から適用値を推定しない。独立した「計算根拠」セクションは設けない。必要な参照値・層数・精錬等の事実値だけを小さな「詳細」へ置く。原文は効果単位で表示し、modifierごとに重複させない。party効果の精錬は提供者の値を使用する。

既存の `sourceText`、`effectDescription`、`labelJa` は原文の証拠にしない。特に `sourceText` は条件・対象推定にも使われるため、表示の都合で原文へ置換しない。表示専用原文はRuntimeの推定・計算に渡さない。

## ヴォジャニーツァのparty入力

party/providerでは元素スキル使用、現在有効な回復回数、命中、反応後の状態、流星嵐の状態、受け手の配置を入力する。C4はHP40%以上のキャラを回復した回数を追加指定する。回復回数だけでC4成立を推定しない。

これらからSong、C1、C2の分岐、C4、A4の対象、14524の蜜酒状態を導出する。凍結／星拡散は自動成立としない。時間進行・期限の自動判定は行わず、現在有効な状態を選ぶ。

既存party condition stateのactionsキーに原因入力を保存する。原因入力があるRequestでは導出条件を再生成し、武器・C4のHP補正を一度適用してからC1／A4／party ATKを評価する。原因入力のない旧Requestは既存の明示条件を維持する。個別modifierの入力UIはこのproviderに限り表示しない。

表示用原文は保存済み完成文を優先し、精錬テンプレートは対応する値を展開する。未展開のテンプレートを表示せず、未知のパラメータキーを詳細表の見出しにしない。生成されたLead Vocal／Chorusラベルは日本語化するが、原文・内部ID・enum・保存値は変更しない。

### 通常操作を優先するprovider UI

主入力は「元素スキル使用後の状態」（未使用／発動直後／1・2・3回目以降の回復後）に統合し、既存のskill／heals保存値へ変換する。新規追加時は未使用。未使用から使用後へ切り替えた場合は、通常の対敵使用として初撃・角笛命中をONにする。以降の例外指定と旧保存値は維持する。

通常表示には凍結／星拡散後5秒以内、計算対象の現在位置、正式名称「流星の嵐」の現在状態だけを追加する。流星の嵐は生成・起爆後の状況で支援対象が変わるため独立指定を残す。命中の例外は詳細設定へ移し、初期値から変更した項目数を見出しに示す。C4のHP条件を満たした回復回数は実計算を左右する主要条件として通常表示する。C4の初期値0回は維持し、対象HPを推定して最大化しない。

HP評価順、条件導出、武器式は変更しない。計算への反映は入力から分離した確認表示とし、原文と実補正値を分離して表示する。

## 条件と実値の共通表示契約

自動導出する内部状態は入力にしない。自動では決められない主要条件は本文に表示する。例外条件だけを詳細設定へ置き、導出結果は確認表示とする。聖遺物・武器・天賦・partyのタブは空欄・不正入力だけを「要設定」、有効な入力は「設定済み」と示し、初回は条件入力のあるタブを開く。ヴォジャニーツァの装備・聖遺物など、操作状態から導出できない手動条件は効果確認の折りたたみから外す。

実装済みの補正項目は0でも残し、「条件未成立」「今回の攻撃には非適用」「計算結果が0」を区別する。固定加算と割合、反応ダメージ補正と基礎ダメージ補正、独立倍率を混同しない。入力反映済みの値は再加算せずその旨を示す。未対応・入力不足・計算不能は数値0にせず、計算対象外または算出不可と表示する。独立攻撃はダメージ一覧への案内にする。

## パーティの情報階層

上位タブ内でサポートメンバーを選び、選択中の1人だけを表示する。名前／Lv／凸、現在の状態（主要条件と例外の詳細設定）、計算への反映（provider集約）、効果説明の順にする。効果一覧はキャラクター／武器／聖遺物で整理し、同じ出典効果から生じる複数modifierを1カードへまとめる。原文は全文を保持し、長文はカード内スクロールにする。数値は項目・実値・0理由の一覧で表示する。

メンバー切替は表示だけを変更し、非表示メンバーの入力と既存party保存契約を維持する。選択中のメンバーが編成から消えた場合は先頭のサポートへ戻る。OFFや0という有効な現在状態、自動導出や効果数を「要設定」とは数えない。

provider集約はRuntimeが採用したmodifierだけを使用する。攻撃種別の適用対象一覧を補正項目として展開しない。基礎ダメージ加算は通常ダメージ側と反応側を分け、ATK割合と固定加算も分ける。独立倍率は既存Runtimeの乗算結果を表示する。実ステータスの固定加算はsourceとmodifierの一致するstat traceを参照し、重複不可／最大値ルールで除外された効果は合計に含めない。効果カードは原文と参照値・層数・精錬の補助情報を表示し、同じ実補正一覧を繰り返さない。

ユーザー提供の確認済み効果内容は、保存原文とは別のconfirmedMechanicsに保持できる。isOriginalText=falseとprovenance=user-confirmed-factsを明記し、「確認済みの効果内容（原文ではありません）」として提供文を表示する。originalText／originalRawへ混ぜず、modifier生成・計算には使用しない。外部参照先と原文全文の収録状況も区別する。
