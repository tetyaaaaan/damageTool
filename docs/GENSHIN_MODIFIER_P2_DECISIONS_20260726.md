# 原神補正 P2 実装判断（2026-07-26）

## 判断基準

- 現在の単発ダメージ計算で、対象・効果量・参照ステータスを一意に決められる補正だけを実装する。
- 独立追撃、特定entry限定、排他的な戦闘状態、ローテーション依存の効果を一般ダメージバフへ置き換えない。
- 安全に計算できない補正には `auditDisposition: dedicatedFormulaDeferred` と具体的な `deferredReason` を持たせ、黙って0または全攻撃対象として適用しない。

## 今回実装した補正

1. ベネット C1
   - 元素爆発の攻撃力アップと同じ発動状態を共有する。
   - 提供者の基礎攻撃力20%を追加の攻撃力固定値としてメインキャラへ反映する。
2. ニコル C2
   - 元素スキルの強化状態を一つのトグルとして扱う。
   - 対象キャラの攻撃力+300と、対象元素の敵耐性-25%を同時に反映する。
