# キャラ・武器入力の画像中心レイアウト

## 採用構造

- キャラと武器は、それぞれ「画像／名前／Lv／凸または精錬」を一つの情報単位として表示する。
- 通常のPC二ペイン表示とスマホでは上下に並べる。
- viewport幅ではなく、入力コンポーネント自身の幅が720px以上の場合だけ2列にする。
- 名前は1行表示とし、固定的な途中改行は入れない。
- 画像と名前の両方から選択モーダルを開ける。

## 横並びをPC標準にしない理由

サイト全体の最大幅は1180pxで、PCでは入力と結果を24pxの間隔を空けて2分割する。入力パネルの左右paddingを除くと、キャラ・武器領域の実効幅はおよそ419〜534pxになる。

この領域をさらに2分割すると1項目あたり約200〜260pxとなり、76px画像と余白を除いた名前領域では、現行最長17文字の武器名「『スーパーアルティメット覇王魔剣』」を安定して表示できない。

## 最小幅の基準

- 360px表示では画像を68px、名前を12pxとする。
- 外側余白、パネルpadding、カードpadding、画像、gapを差し引いて、名前領域を約222px確保する。
- 現行最長武器名を1文字12pxとして見積もると204pxで、固定改行なしで収まる。
- 390px以上では画像76px、名前13pxでも同じ名称を表示できる。

## 将来のレイアウト変更

入力と結果を上下配置に変更して入力領域が広がった場合、コンテナクエリにより同じHTMLのままキャラと武器が2列になる。PC用とスマホ用にDOMを複製しない。
